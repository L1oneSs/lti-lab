# Комплект сдачи лабораторной

Это подготовленная часть комплекта, а не заявление о завершении всех проверок. Отчёт и материалы проекта готовы; доказательства оценок двух студентов в настоящем Moodle ещё отсутствуют.

| Материал | Где находится | Состояние |
|---|---|---|
| Исходники, зависимости, пример конфигурации | Корень репозитория, `src/`, `public/`, `package-lock.json`, `.env.example` | Готово |
| Инструкция запуска | `../CODESPACES.md`, `../README.md` | Готово |
| Описание вопросов и правил | `REPORT.md` | Готово |
| Схема и повторная отправка | `REPORT.md`, `../DEFENSE.md` | Готово |
| Ответы на шесть вопросов защиты | `../DEFENSE.md` | Готово |
| Собственные дополнительные тесты | `../test/grading.test.mjs` | Готово, три дополнительных теста |
| Фактический вывод локального `npm test` | `evidence/npm-test.txt` | 7 pass, 0 fail |
| Результаты А/Б и отрицательные проверки | `CHECKS.md` | Таблица подготовлена; фактические результаты не получены |
| Скриншоты настоящего Moodle | `evidence/` | Файлы пока отсутствуют |

Перед сдачей заполнить `CHECKS.md` по реальным проверкам, добавить снимки и сведения об авторе в `REPORT.md`. Не выдавать ожидаемые баллы за фактически полученные. Тесты на имитации подписанного запуска и AGS помечены отдельно.

Локальный архив комплекта находится рядом с каталогом репозитория: `LTI-LAB-SUBMISSION.zip`. Он создан из версии Git без `.env`, `node_modules`, `data`, ключей, `.git` и локальных служебных каталогов. Если после его создания добавлены снимки или изменён отчёт, архив нужно пересобрать из обновлённой версии.
